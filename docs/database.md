# قاعدة بيانات أبو مشعل

يتضمن مخطط البيانات كيانات المستخدمين والمنشآت والجهات والخدمات وطلبات الخدمة والمعاملات وسجل الحالة والمهام والمواعيد والمستندات والتنبيهات. تستخدم الجداول معرّفات متزايدة وطوابع إنشاء وتحديث، مع فهارس للملكية والحالة والاستعلامات التشغيلية المتكررة.

| المجال | الجداول | الغرض |
|---|---|---|
| الحسابات والمنشآت | `users`، `organizations`، `organization_members` | تعريف المستخدمين وعزل منشآت العملاء |
| الكتالوج | `government_entities`، `government_services` | الجهات والخدمات المرجعية بلا شعارات أو ادعاء تمثيل |
| المتابعة | `service_requests`، `transactions`، `transaction_status_history` | طلب العميل والمعاملة التشغيلية وتاريخ الحالة |
| التنفيذ | `tasks`، `appointments`، `documents` | العمل المطلوب والمواعيد والمرفقات |
| التواصل | `notifications` | إشعارات داخل التطبيق وحالة القراءة |

قبل إضافة أي جدول أو حقل، عُدّل `drizzle/schema.ts` ثم شغّل `pnpm drizzle-kit generate` وراجع SQL الناتج قبل تطبيقه. لا تُضاف بيانات حقيقية إلى بيئة المعاينة.

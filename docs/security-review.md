# مراجعة الأمان والخصوصية

## ضوابط مطبقة في النسخة الحالية

| المجال | الضابط |
|---|---|
| الحسابات | تسجيل الدخول عبر OAuth المهيأ للمشروع، مع استخدام جلسة الحساب لتحديد مالك البيانات على الخادم |
| عزل البيانات | سجلات المزامنة السحابية مقيدة بـ `ownerUserId` مشتق من الجلسة، ومفاتيح التخزين المحلية مفصولة لكل حساب |
| الصلاحيات | واجهات الطلبات والمعاملات والمستندات تستخدم إجراءات مصادقاً عليها، وتُطبَّق صلاحيات التشغيل على الخادم |
| الملفات | يدعم الرفع PDF وJPG وPNG وDOCX فقط، بحد 5 ميغابايت، مع فحص الاسم والنوع والحجم على الخادم قبل التخزين |
| المزامنة | يحتفظ التطبيق بنسخة محلية إذا انقطع الاتصال ولا يمرر معرّف المالك من الواجهة إلى الخادم |
| السجلات | لا تضيف الواجهات بيانات شخصية حساسة إلى رسائل السجل أو أخطاء المستخدم |

## حدود يجب استكمالها قبل الاستخدام الإنتاجي الموسع

تحتاج النسخة إلى تحديد سياسة احتفاظ وحذف للملفات، ومراجعة مستقلة لمكافحة البرمجيات الخبيثة، ومعدل طلبات على مستوى البوابة، ومراقبة مركزية للأخطاء وسجل تدقيق غير قابل للتعديل. كما أن التحقق بخطوتين ورسائل SMS وواتساب والمدفوعات تحتاج مزودين رسميين وإعدادات اعتماد منفصلة؛ ولم تُضف في هذه النسخة.

لا تمثل المنصة أي جهة حكومية، ولا تُستخدم لربط غير مصرح به مع منصات أو سجلات حكومية.

# نموذج الصلاحيات الأولي لأبو مشعل

تنفذ واجهات الخدمة القاعدة التالية: يرى العميل سجلاته فقط، بينما يرى الموظف السجلات التشغيلية اللازمة لأداء العمل، ولا يستطيع تغيير حالة المعاملة أو إنشاء معاملة تشغيلية إلا مشرف أو مدير. تُطبق هذه القاعدة على الخادم، ولا تعتمد على إخفاء أزرار الواجهة فقط.

| العملية | عميل | موظف | مشرف / مدير |
|---|---:|---:|---:|
| عرض طلباته ومعاملاته | نعم، ضمن ملكيته | نعم، وفق نطاق التشغيل | نعم |
| إنشاء طلب خدمة | نعم | نعم | نعم |
| إنشاء معاملة تشغيلية من طلب | لا | لا | نعم |
| تغيير حالة معاملة | لا | لا | نعم |
| تعيين مسؤول أو تحديث الإجراء التالي | لا | لا | نعم |

ستتوسع هذه السياسة لاحقاً بعزل المنشآت، وعضوية المنظمة، وسجل تدقيق لكل عملية حساسة. لا تُعرض الملاحظات الداخلية أو المستندات المقيدة لعميل لا يملك حق الاطلاع عليها.

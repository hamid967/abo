# اختبار تنبيهات مواعيد المعاملات

تعمل الميزة كتذكيرات محلية محفوظة على الجهاز. عند إضافة معاملة أو تعديلها، يختار المستخدم تفعيل التذكير ثم يحدد التقديم: يوم الموعد، أو قبل يوم، أو ثلاثة أيام، أو أسبوع، ويحدد كذلك الساعة والدقيقة بدقة. يطلب التطبيق إذن الإشعارات عند الحفظ، ويعيد جدولة التذكير عند تغيير التاريخ أو الوقت أو إعدادات التقديم، ويلغيه عند الحذف أو عند وضع المعاملة في حالة مكتملة.

| خطوة الاختبار | الإجراء | النتيجة المتوقعة |
|---|---|---|
| تفعيل الإذن | افتح «الإعدادات» ثم اضغط «تفعيل الإشعارات»، أو فعّل التذكير عند حفظ معاملة. | يظهر طلب إذن النظام، ثم تتغير البطاقة إلى «التنبيهات مفعّلة» بعد الموافقة. |
| إنشاء تذكير | أضف معاملة بتاريخ مستقبلي وفعّل التذكير، ثم اختر مدة التقديم والساعة والدقيقة. | يحفظ التطبيق المعاملة ويضع تذكيراً محلياً في الوقت المحسوب بدقة. |
| تعديل الوقت | عدّل تاريخ المعاملة أو مدة التقديم أو الساعة أو الدقيقة ثم احفظ. | يُلغى التذكير السابق ويُنشأ تذكير جديد للوقت المحدَّث. |
| إلغاء التذكير | احذف المعاملة أو غيّر حالتها إلى «مكتملة». | يُلغى أي تنبيه مجدول لتلك المعاملة. |

> يجب إجراء اختبار وصول الإشعار على جهاز iOS أو Android فعلي بعد إنشاء نسخة جوّال جديدة، لأن المعاينة عبر الويب لا تعرض الإشعارات المحلية. تدعم مكتبة Expo جدولة الإشعارات المحلية، وتوضح وثائقها أن إعدادات المكوّن الإضافي تتطلب إعادة بناء نسخة التطبيق لتنعكس إعدادات المنصة. [1]

## ملاحظات التشغيل

يُشغَّل التذكير في الساعة والدقيقة اللتين يختارهما المستخدم بالتوقيت المحلي للجهاز في اليوم الناتج بعد تطبيق مدة التقديم. يبدأ الحقلان افتراضياً عند 09:00، ويمكن إدخال ساعة بين 00 و23 ودقيقة بين 00 و59. لا يسمح التطبيق بجدولة تذكير في وقت مضى أو لتاريخ أو وقت غير صالح. لا يرسل التطبيق بيانات المعاملات إلى خادم أو خدمة حكومية؛ جدولة الإشعار تتم محلياً على الجهاز.

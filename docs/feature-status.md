# حالة ميزات أبو مشعل

| الميزة | الحالة | ملاحظات |
|---|---|---|
| متابعة الطلبات والحالات | منفذة | تخزين محلي وسجل زمني في الواجهة، مع مخطط وAPI للتمدد |
| التنبيهات الدقيقة | منفذة | محلية على الجهاز وتتطلب بناء جوال جديد لاختبار الإشعار |
| المهام والمواعيد والمستندات | منفذة مبدئياً | اختيار مرفقات محلي؛ الرفع السحابي الدائم مرحلة لاحقة |
| أدوار العميل والموظف والمشرف | منفذة للمعاينة | الصلاحيات الحقيقية موجودة في طبقة API وتحتاج ربط تسجيل دخول إنتاجي |
| استفسارات ومساعد إرشادي | منفذة | مساعد محلي في الواجهة ونقطة خادم للإجابة الإرشادية |
| دفع ورسائل SMS وواتساب | مؤجلة | تتطلب مزودين رسميين واعتمادات منفصلة |
| تكامل حكومي مباشر | غير منفذ | لا يفعّل دون تفويض قانوني وتقني واضح |

# مراجعة فريق العمل: أبو مشعل

## خلاصة المراجعة

تمت مقارنة النسخة الحالية بمواصفات الفريق. تحتوي النسخة على الهوية العربية، دورة حالات موسعة، سجل متابعة، تنبيهات محلية، حساب OAuth، مزامنة سحابية مملوكة للمستخدم، مساحة مهام ومواعيد، مركز استفسارات، مساحات معاينة تشغيلية، ومخطط بيانات محمي بعلاقات مرجعية. لا تدّعي المنصة أي تكامل مباشر مع الجهات الحكومية، وتبقى المعلومات إرشادية.

## فجوات الأولوية

| الأولوية | الفجوة | قرار الإصدار |
|---|---|---|
| عالية | إرسال الطلب لا يحفظ بعد في كيان الطلب التشغيلي الكامل | ربط المعالج بواجهة طلبات محمية وإضافة موافقات الخصوصية والشروط |
| عالية | اختيار المستندات يحفظ وصفاً محلياً فقط | رفع الملف إلى التخزين المهيأ بعد التحقق من النوع والحجم وربطه بحساب المستخدم |
| عالية | التواصل موجود كتذكرة مبسطة لا كسجل ردود تفصيلي | إضافة رسائل تذكرة مرئية للعميل وتحويلها إلى موظف، مع فصل الملاحظات الداخلية |
| متوسطة | مساحة المهام لا توفر لوحة Kanban أو تقويماً تشغيلياً | إضافة طريقتي عرض دون تغيير المسار الحالي للقائمة |
| متوسطة | التقارير مرئية فقط | توثيق التصدير كمرحلة لاحقة إلى أن تتوفر بنية ملفات وتقارير معتمدة |
| مؤجل | المدفوعات وSMS وواتساب والتحقق بخطوتين | لا تنفذ من دون مزود رسمي وعقود وبيانات اعتماد صالحة |

## افتراضات ومخاطر

تُستخدم مصادقة المشروع المهيأة لتمييز المستخدم. أي اختبار متكامل لتبديل الحسابات يحتاج حسابين فعليين على جهازين أو جلستين منفصلتين. تخزين المستندات يقتصر على ملفات عملية وبأحجام مضبوطة؛ ولا تُعامل هذه النسخة كنظام حفظ سجلات حكومي أو كبديل لقرار الجهة المختصة.

## نطاق الاستكمال الحالي

يركز الاستكمال على ربط الطلب والمستندات والاستفسارات بالسحابة، وعلى تحسين أدوات التشغيل. لا يُضاف تكامل حكومي غير مصرح به، ولا تُضاف بوابات دفع أو قنوات رسائل خارجية دون موفر رسمي وبيانات اعتماد.

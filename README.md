# أبو مشعل

تطبيق جوال عربي مستقل لمتابعة الطلبات والمعاملات والمهام والمواعيد. لا يمثل التطبيق أي جهة حكومية ولا يربط الخدمات الحكومية مباشرةً.

## التشغيل المحلي

| الأمر | الغرض |
|---|---|
| `pnpm dev` | تشغيل خادم الواجهة والخدمات المحلية |
| `pnpm check` | فحص TypeScript |
| `pnpm test` | تشغيل اختبارات Vitest |
| `pnpm lint` | فحص معايير Expo |
| `pnpm drizzle-kit generate` | توليد هجرة قاعدة البيانات بعد تعديل المخطط |

## وحدات النسخة الحالية

تشمل النسخة الحالية لوحة متابعة، معالج طلب جديد، دورة حالات موسعة وسجل متابعة، تنبيهات محلية بمواعيد دقيقة، مساحة مهام ومواعيد ومستندات، أدوار معاينة للعميل والموظف والمشرف، استفسارات مع تحويل للفريق، مساعداً إرشادياً، ولوحة تقارير تشغيلية.

## الحدود الحالية

تُحفظ بيانات المعاينة محلياً في الجهاز، بينما تم تجهيز مخطط قاعدة البيانات وواجهات خدمة محمية للتوسع إلى حسابات ومزامنة حقيقية. يجب عدم تفعيل ربط حكومي أو رسائل خارجية أو دفع إلا بعد التحقق من الاعتمادات القانونية والتقنية وتوفير المزود المناسب.

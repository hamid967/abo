# أبو مشعل

تطبيق جوال عربي مستقل لمتابعة الطلبات والمعاملات والمهام والمواعيد والمستندات، مع مركز دعم بتذاكر ورسائل محمية، ومركز معرفة، وإشعارات داخل التطبيق، ولوحة إدارة مقيدة بالأدوار. لا يمثل التطبيق أي جهة حكومية ولا يربط الخدمات الحكومية مباشرةً.

## التشغيل المحلي

| الأمر | الغرض |
|---|---|
| `pnpm dev` | تشغيل خادم الواجهة والخدمات المحلية |
| `pnpm check` | فحص TypeScript |
| `pnpm test` | تشغيل اختبارات Vitest |
| `pnpm lint` | فحص معايير Expo |
| `pnpm drizzle-kit generate` | توليد هجرة قاعدة البيانات بعد تعديل المخطط |

## وحدات النسخة الحالية

تشمل النسخة الحالية لوحة متابعة، معالج طلب جديد، دورة حالات موسعة وسجل متابعة، تنبيهات محلية بمواعيد دقيقة، مساحة مهام ومواعيد ومستندات، تسجيل دخول ومزامنة سحابية، تذاكر دعم ورسائل خادمية، مركز معرفة وأسئلة شائعة، إشعارات داخل التطبيق، بحثاً محمياً، مساعداً إرشادياً مقيداً بالمصادر المنشورة، ولوحات تشغيل وإدارة مع سجل تدقيق.

## الحدود الحالية

تُحفظ بيانات المعاينة محلياً في الجهاز، وتدعم الحسابات المسجلة مزامنة سحابية محمية. لا تُفعل رسائل SMS أو واتساب أو البريد التشغيلي أو المدفوعات أو أي ربط حكومي إلا بعد اعتماد قانوني وتقني ومزود خدمة مناسب. تحفظ الأسرار في إعدادات البيئة بالمنصة فقط ولا تُضاف إلى المستودع.
